# Content workflow: what really works

HQ, More, Content. **HQ never posts, schedules or contacts any social service.** It is a record and a reminder. There is no Facebook or Google Business Profile connection (none found, none tested). Publishing is done by you, in Meta Business Suite or Google Business Profile.

| Step | Works? | How it is tested |
|---|---|---|
| Write a post (title, text, Facebook, Google or both, optional day and picture idea) | **Works** | HQ test: created as a draft, bad or short input refused |
| The 14-day content pack | **Works** (14 drafts, canonical prices, banned claims test) | HQ and pack tests |
| Edit a post | **Works**; any edit sends it back to draft; a posted post cannot be edited | HQ test |
| Review and approve or reject | **Works**; sensible moves only (draft, approved, scheduled, posted, rejected) | HQ test |
| Founding-offer guard | **Works**; a post that mentions the founding offer cannot be approved, scheduled or posted when all five places are used or the count cannot be checked; applies to your own posts and to edits | HQ tests, fail-closed case included |
| Plan a platform and a day | **Works** | HQ test |
| "I scheduled it" and "It is posted" | **Works as a tick box only**: it records that you did it, it does not do it | HQ test |
| Home reminder "N posts to put out today" | **Works** for approved or scheduled posts whose planned day has come, until you tick them posted | HQ test |
| Actually scheduling or publishing to Facebook or Google | **Not built, not live.** Needs a Meta app, Google API access and your approval of each connection | none |
| Copy-to-clipboard button | **Not built** (HQ pages carry no scripts for safety). Select the text box and copy | none |

Everything marked works is tested with a fake backend. It has not been used on the live HQ yet: your first real check is writing one post in HQ, approving it, giving it today's date, and seeing the Home reminder.

Your routine: write or edit, approve, plan a day, schedule it in Meta Business Suite (or Google), tick "I scheduled it", and once it is out tick "It is posted".
